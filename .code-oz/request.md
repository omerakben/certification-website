# SPEC

## Goals

- Create a website that hosts links to free certification programs from trusted providers
- Focus on reputable sources: Google Education, Microsoft Education, Anthropic, OpenAI, and other established tech companies
- Provide a clean, user-friendly interface for browsing and accessing these certifications
- Include brief descriptions of each certification program and what skills they cover
- Make it easy for users to find relevant free learning opportunities

## Users

- Students and professionals looking to upskill with free, reputable certifications
- Career changers seeking validated credentials from industry leaders
- Lifelong learners wanting to stay current with technology trends
- Anyone seeking free, high-quality educational resources from trusted sources

## Constraints

- Website must be static (HTML/CSS/JS) or use a simple static site generator
- All linked certification programs must be genuinely free and from verified sources
- No paid courses or programs that require payment for certification
- Focus on technology-related certifications (cloud, AI, programming, data science, etc.)
- Each certification entry must include: provider name, certification title, brief description, link to official program, and skills covered
- Website should be responsive and work well on mobile and desktop
- Source code should be maintainable and follow web development best practices
- No external dependencies beyond standard web technologies unless absolutely necessary
