# Free Certification Programs Website

A curated directory of free certification programs from trusted providers like Google, Microsoft, Anthropic, and OpenAI.

## Features
- Lists free certification programs from reputable tech companies
- Links directly to official provider pages
- Organized by provider for easy browsing
- Includes brief descriptions and skills covered

## Providers Included
- Google Education
- Microsoft Education
- Anthropic
- OpenAI

## How to Use
Simply browse the certification items and click "Learn More" to visit the official provider page for detailed information and enrollment.

## Disclaimer
This site only provides links to official certification programs. We do not host, reproduce, or issue any certification content.
